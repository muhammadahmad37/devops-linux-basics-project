# Linux Basics on AWS EC2

## Project Overview

This project demonstrates practical Linux fundamentals
performed on an AWS EC2 Ubuntu server.

## Topics Covered

- Linux Server Information
- Filesystem Navigation
- Directory and File Creation
- Writing and Reading Files
- Copying and Moving Files
- Deleting Files and Directories
- Viewing Log Files
- Real-Time Log Monitoring
- Linux File Permissions
- Final Project Verification

## Tools and Technologies

- AWS EC2
- Ubuntu Linux
- Linux CLI
- SSH

## Project Structure

- app/
- scripts/
- documentation/
- screenshots/

## Learning Objective

To develop practical Linux command-line skills
required for DevOps engineering.
